# Technology Normalization

The scaling module implements the public DeepScaleTool node tables as a
non-interactive command. It is distributed under GPLv3 because the reference
tables come from the GPLv3 workbook retained in `vendor/`.

The rest of SCARF remains under the repository license. Keeping the scaling
module and its vendor material in this directory makes the license boundary
explicit. Generated estimates preserve the raw ASAP7 record and state that the
output is not a foundry measurement.
