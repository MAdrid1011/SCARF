# 设计来源与约束

这一章规定模拟器设计的证据优先级、模块边界和参数来源。实施者只能在这些边界内补齐端到端执行所需的支撑逻辑。

## 证据优先级

设计证据按以下顺序解释。

1. 期刊论文中的数据流、架构和实验方法章节
2. 官方模型代码、官方预训练权重和官方评测配置
3. 真实工作负载产生的张量形状、执行追踪和渲染结果
4. 本目录保存的静态锚点和论文对照表
5. 开源 DRAM 模型、器件数据手册和经过记录的微基准

静态锚点用于实施前检查，不覆盖真实测量。论文对照值用于发现明显偏差，不允许写入模拟器作为返回结果。

## 论文阶段

SCARF 包含四个逻辑阶段。

- S1 接收多视图图像并生成多尺度特征。RMCF 在可连接 S2 的层间边界执行探针匹配，并停止已收敛区域的后续特征增强。
- S2 对探针或 tile 像素执行跨视图采样、代价体构建、代价体精化和深度回归。FSDR 只改变完整深度路径的候选集合，不改变候选值本身和后续网络。
- S3 根据 tile 的局部证据选择 SAES 代表路径、轻量路径或完整逐像素 Gaussian Adaptor。
- S4 将网络输出转换为可渲染的 Gaussian 基元，并以紧凑格式流式提交。

模拟器中的阶段标签只用于归属周期。实际调度必须保留 S1 与 S2 的区域级交错、S2 与 S3 的 tile 级交接，以及 GGU 与下一 tile 的重叠。

## 论文核心模块

### 矩阵向量单元

MVU 包含 $48\times48$ MMCU、BilinearUnit、VectorALU、NormUnit 和 ActivationUnit。MMCU 执行 S1 至 S3 中的 Conv、GEMM 和 Attention。BilinearUnit 对 32 维通道组执行四点插值、参考特征乘法和归约。VectorALU 执行概率归一化、深度期望、RMCF 收敛统计、FSDR 控制统计和 SAES 路径统计。

### FSDR 缓存

FSDR 缓存包含 32 个 41 位 CAM 条目。每个条目保存有效位、16 位 LSH 签名、FP16 深度锚点和 8 位 LRU 状态。查询先并行计算 32 个汉明距离，再读取最佳条目并完成阈值比较。命中时，局部候选数量为完整候选数量的四分之一。

### Gaussian 生成单元

GGU 阵列包含 32 个处理单元。每个处理单元具有 PositionCalc、CovBuilder 和 SH_OPGenerator 三级流水。GGU 接收 S3 输出并产生 $\{\mu,\Sigma,\alpha,\mathbf c_{sh}\}$。位置和协方差路径使用 FP32。允许使用 FP16 的路径只限论文明确允许的非几何关键计算。

### 控制与片上存储

控制子系统维护 Region FIFO、Tile FIFO、Request FIFO、Reference FIFO、Tag FIFO、PSum RAM、任务依赖和流水状态。SPM 包含 128 KB 权重缓冲区、256 KB 特征缓冲区和 64 KB tile 缓冲区。实现可以补充描述符存储、统计计数器和结果队列，但这些结构只能闭合控制路径，不能绕过核心计算。

## 核心机制边界

RMCF 只能依据中间匹配概率和前后深度一致性停止区域后续工作，并将活动块组织为规则矩形任务。FSDR 只能依据 LSH 签名查询深度锚点并收缩候选集合。SAES 只能依据 tile 探针证据选择最小 Gaussian 实例化路径。新 SAES 重建方法是 SAES 内部的质量保持实现，不是第四个优化模块。

## 无魔数配置合同

所有配置项采用以下记录形式。

```yaml
mmcu_rows:
  value: 48
  source_kind: paper
  source: Architecture.md#矩阵向量单元
  derivation: 期刊架构明确规定的阵列行数
```

允许的 `source_kind` 为 `paper`、`official_model`、`dataset`、`device_datasheet`、`measured`、`calibrated`、`derived` 和 `user_requirement`。`calibrated` 参数必须同时记录校准数据集、分割、搜索目标、质量约束和生成提交。`derived` 参数必须记录公式及其输入来源。

模拟器启动时遍历生效配置。除布尔开关、张量维度和数学恒等式外，任何缺少来源字段的数值都导致运行失败。代码中不得出现未进入配置和推导系统的阈值、带宽、延迟、队列深度或经验倍率。

## 明确排除的内容

- 不读取旧 SCARF 模拟器实现来推断正确行为
- 不根据论文柱状图反推单次运行周期
- 不生成能效、功耗、面积或面积归一化吞吐率
- 不使用商业综合、商业存储器编译器或闭源性能库
- 不用随机输入替代不可获得的数据集
- 不用质量均值替代逐视图结果和最坏视图结果
