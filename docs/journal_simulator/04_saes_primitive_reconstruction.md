# SAES 固定路径基元重建

这一章只替换 SAES 已进入 L0 或 L1 后的软插值计算。论文定义的 L0、L1、Full 判定、探针位置、触发比例、任务取消时机和路径统计均保持不变。新算法不得增加路径、减少路径、改变阈值，也不得在选中 L0 或 L1 后转入 Full。Full 路径的功能和周期语义完全不变。

该设计是工程优化方案，不主张新的学术新颖性。局部 Gaussian 矩匹配与高斯混合约简已有直接先例。这里的目标是把质量保持原则用于前馈 G-3DGS 的预实例化省略场景，同时保留 SAES 跳过非探针 Adaptor 的全部加速来源。

## 约束与失败原因

现有软插值不能直接视为 Gaussian 重建。

1. 被省略像素没有执行 Adaptor，因此不存在可供线性插值的真实 Gaussian 属性。
2. 对 opacity 做算术平均不保持前向合成中的 transmittance，也不保持局部积分光学厚度。
3. 对旋转、尺度或协方差分量直接插值不能保证结果仍是对称正定协方差。
4. 对球谐系数做跨探针平均会混合边界颜色、阴影和视角相关项。
5. 带有人工空间、特征和深度权重的 softmax 同时引入魔数、指数运算和额外归约。

因此，新算法不估计每个被删像素的完整 Gaussian，也不混合不同探针的属性。它把每个真实探针 Gaussian 扩展为一个由其负责的局部覆盖基元。

## 方案选择

| 候选 | 质量依据 | SAES 加速保留 | 路径集合 | 结论 |
| --- | --- | --- | --- | --- |
| 先生成全部 Gaussian 再局部合并 | 真实基元 | 低，完整 Adaptor 已执行 | 不变 | 拒绝 |
| 增加轻量神经残差头 | 依赖再训练 | 中 | 增加预测支路 | 拒绝 |
| 探针 Gaussian 驱动的硬归属与矩守恒 | 真实几何、opacity 和 SH | 高，不执行非探针 Adaptor | 不变 | 采用 |

采用方案没有新的消融开关，也不形成第四项核心技术。它使用已有 Adaptor、VectorALU、GGU 和 64 KB tile 缓冲区完成计算。

## 固定路径接口

论文路径选择器先输出每个 tile 的不可变标签

\[
r_t\in\{\mathrm{L0},\mathrm{L1},\mathrm{Full}\}.
\]

该标签在重建开始前写入任务描述符。重建器只有以下接口。

```text
reconstruct_fixed_path(path_label, probe_pixels, probe_gaussians,
                       tile_pixels, camera, adaptor_inputs)
```

- `path_label == Full`：直接执行论文 Full 路径，不调用本章算法。
- `path_label == L0`：使用论文 L0 已有的探针深度和 Gaussian，执行本章算法。
- `path_label == L1`：使用论文 L1 已验证的探针深度和 Gaussian，执行同一算法。

重建器不返回新路径标签。任何数值异常都使本次运行失败并输出诊断，不允许通过改变 tile 路径掩盖错误。替换前后的 `path_label` 张量、各路径 tile 数量和被取消任务集合必须逐元素一致。

## 步骤 1：由探针拟合局部三维支撑

所有探针仍执行官方 Gaussian Adaptor，并由已有 GGU 得到

\[
G_p=(\mu_p,\Sigma_p,\alpha_p,h_p),
\]

其中 \(\mu_p\) 是世界坐标中心，\(\Sigma_p\) 是三维协方差，\(\alpha_p\) 是 opacity，\(h_p\) 是球谐系数。探针的投影像素为 \((u_p,v_p)\)，相机坐标深度为 \(z_p\)。

为保证深度为正，在 tile 内拟合仿射 log-depth 表面

\[
\log z_p=[u_p,v_p,1]\theta+\varepsilon_p.
\]

权重来自探针协方差沿相机视线投影得到的深度方差，而不是人工距离带宽。令单位视线为 \(r_p\)，则权重由 \((r_p^\mathsf{T}\Sigma_pr_p)^{-1}\) 给出；分母的数值下界使用后文相同的数据类型正定投影规则。令设计矩阵为 \(A\)，权重矩阵为 \(W\)，则

\[
\theta=(W^{1/2}A)^+W^{1/2}\log z.
\]

上标 \((\cdot)^+\) 表示 Moore--Penrose 伪逆。奇异值截断只使用数据类型精度与矩阵维度推导的标准容差

\[
\mathrm{tol}=\epsilon_{\mathrm{dtype}}\max(m,n)\sigma_{\max},
\]

不设置经验阈值。若探针布局秩不足，伪逆给出确定性的最小范数解，不改变 L0 或 L1 标签。

对 tile 中每个被省略像素 \(i\)，计算

\[
z_i=\exp([u_i,v_i,1]\theta),\qquad
X_i=T_{cw}\left(z_iK^{-1}[u_i,v_i,1]^\mathsf{T}\right).
\]

这一步只恢复归属计算所需的三维支撑点，不运行非探针 Adaptor，也不生成被省略像素的 Gaussian。

## 步骤 2：基于真实基元贡献的硬归属

对每个被省略像素 \(i\) 和探针 \(p\)，使用探针 Gaussian 对该点的负对数贡献作为归属分数。首先定义数据类型安全的光学厚度

\[
\tau_p=-\log(1-\alpha_p).
\]

opacity 的开区间边界由 `nextafter(0, 1)` 和 `nextafter(1, 0)` 产生，不使用手写常数。探针球谐在像素对应视线方向 \(d_i\) 上求值得到 \(c_p(d_i)\)。令 \(I_i\) 为生成该 Gaussian 的上下文像素颜色，\(\Gamma_I\) 为当前 tile 颜色的经验协方差，则

\[
\begin{aligned}
s_{ip}={}&\frac{1}{2}(X_i-\mu_p)^\mathsf{T}\Sigma_p^{-1}(X_i-\mu_p)
+\frac{1}{2}\log\det\Sigma_p-\log\tau_p\\
&+\frac{1}{2}(I_i-c_p(d_i))^\mathsf{T}\Gamma_I^+(I_i-c_p(d_i)).
\end{aligned}
\]

前三项是 Gaussian 空间密度与光学厚度产生的负对数贡献，最后一项是由真实球谐外观产生的颜色似然。两者组成联合似然，因此没有人为的几何/颜色混合权重。\(\Gamma_I^+\) 使用与上一步相同的、由数据类型和矩阵维度推导的伪逆容差。

硬归属为

\[
a(i)=\arg\min_p s_{ip}.
\]

分数相同则按论文固定的探针光栅顺序选择。该计算只有二次型、对数和 `argmin`，删除旧算法的逐像素指数、softmax 和加权属性归约。所有权集合 \(V_p\) 包含探针自身，因此每个保留探针至少代表一个像素。

## 步骤 3：几何覆盖矩更新

令探针自己的三维支撑为 \(X_p=\mu_p\)。对 \(V_p\) 中的全部支撑点计算

\[
\bar X_p=\frac{1}{n_p}\sum_{i\in V_p}X_i,
\]

\[
C_p=\frac{1}{n_p}\sum_{i\in V_p}
(X_i-\bar X_p)(X_i-\bar X_p)^\mathsf{T},
\qquad n_p=|V_p|.
\]

更新后的保留基元为

\[
\mu'_p=\bar X_p,\qquad
\Sigma'_p=\Pi_{\mathrm{SPD}}(\Sigma_p+C_p).
\]

\(C_p\) 是当前相机、探针深度和归属像素共同决定的精确覆盖二阶矩。正定投影只修复浮点舍入：协方差特征值下界由

\[
\lambda_{\min}=d\,\epsilon_{\mathrm{dtype}}
\max(\|\Sigma_p+C_p\|_2,\mathrm{tiny}_{\mathrm{dtype}})
\]

推导，其中 \(d=3\) 是矩阵自身维度，不是可调参数。投影不会触发新路径。

## 步骤 4：光学厚度质量守恒

定义未归一化的局部光学质量

\[
m_p=n_p\tau_p\sqrt{\det\Sigma_p}.
\]

常数 \((2\pi)^{3/2}\) 在更新前后抵消。扩展后的探针保持该质量：

\[
\tau'_p=\frac{m_p}{\sqrt{\det\Sigma'_p}},\qquad
\alpha'_p=1-\exp(-\tau'_p).
\]

该更新保持局部积分光学厚度，不使用 opacity 算术平均。几何计算、行列式、对数和指数至少使用 FP32；最终 opacity 只按目标数据类型的可表示开区间裁剪。

## 步骤 5：保持球谐与输出数量

球谐不跨探针插值：

\[
h'_p=h_p.
\]

因此，边界颜色、阴影和高阶视角项不会被相邻探针平均。输出 Gaussian 的数量和身份与论文原 L0/L1 保留探针完全一致。每个输出只更新中心、协方差和 opacity；旋转与尺度由已有 GGU 对 \(\Sigma'_p\) 做分解得到。

## L0、L1 和 Full 的不变量

L0 与 L1 保留论文各自的输入条件和前序深度工作。两条路径进入后使用相同的硬归属、覆盖矩与光学厚度守恒更新。Full 路径执行全部像素的原始深度与 Gaussian Adaptor，不执行覆盖吸收。

模拟器必须对替换前后的以下对象做逐元素比较。

1. L0、L1、Full 路径标签张量
2. 各路径 tile 数量与比例
3. 探针位置与数量
4. 被取消的 S2、S3 任务集合
5. L0/L1 输出 Gaussian 数量

任何一项不同都属于路径语义被改变，而不是重建算法改进。

## 周期与存储映射

探针 Gaussian 写入现有 tile 缓冲区的临时地址区。log-depth 拟合、二次型、颜色协方差、`argmin`、覆盖矩和光学厚度归约映射到已有 VectorALU；协方差分解映射到已有 GGU。临时容量由最大探针数、tile 像素数和 Gaussian 格式推导，并计入 64 KB tile 缓冲区，不新增存储模块。

周期模型必须分别记录表面拟合、硬归属、覆盖矩、光学更新和 GGU 分解周期。不得把这些步骤合成平均的“每 tile 开销”。新路径不执行非探针 Adaptor，并删除旧软插值的 softmax 和跨探针属性加权，因此其单 tile 工作量必须不高于原 L0/L1 内部实现；若实测不满足，方案不能合入。

GPU 功能实现按视图批量处理 tile。热路径禁止逐 tile `.item()`、`.cpu()` 或主机分支。路径标签只在批次结果落盘时传回 CPU。

## 接受条件

新重建算法只有同时满足以下条件才可替代旧软插值。

1. 替换前后的路径标签、路径比例、探针和取消任务集合逐元素一致。
2. 官方模型与真实数据集的每个视图均输出 PSNR、SSIM 和 LPIPS。
3. 所有组合的最坏视图质量变化满足实验合同，不能只看平均值。
4. SAES 单独端到端周期不高于论文 SAES 对照，且不高于旧软插值实现。
5. All 周期与主端到端周期完全一致。
6. 没有新增 Full tile、没有隐藏的路径转移、没有逐 tile GPU 到 CPU 同步。
7. 所有数值容差均由数据类型、矩阵维度或输入统计推导，没有手写经验常数。

若质量未通过，判定本章内部重建算法未通过并继续修改算法。不得改变 L0/L1/Full 选择、放宽质量合同或牺牲吞吐来掩盖失败。
