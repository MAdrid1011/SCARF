# 高斯简化相关工作审计

本页记录为 SAES 质量修复执行的外部检索。当前输出是工程优化 brief，不是论文级新颖性声明。没有把新重建路径包装为 SCARF 的第四项贡献。

## 检索范围

本轮没有可复用的既有高斯合并调研。新增检索覆盖三个方向。

- 3D Gaussian 基元和 alpha 合成的原始定义
- 3DGS 裁剪、恢复、简化和量化
- 经典高斯混合矩匹配与局部合并代价

仍待实施阶段补充的是各方法公开代码中的数值稳定处理，以及 NanoGS 在各向异性协方差和球谐属性上的完整实现细节。这些问题不阻塞当前设计，因为固定路径内部重建的每一步都要由真实渲染质量验证。

## 保留文献

### 3D Gaussian Splatting

[3D Gaussian Splatting for Real-Time Radiance Field Rendering](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/) 定义了位置、各向异性协方差、不透明度和球谐颜色，以及基于可见性顺序的 alpha 合成。它说明不透明度和协方差共同决定一个基元的图像贡献，因此直接平均 opacity 没有物理保持保证。

### LightGaussian

[LightGaussian](https://arxiv.org/abs/2311.17245) 使用全局重要性裁剪、训练视图上的恢复微调和球谐蒸馏。它证明保留基元需要对裁剪损失进行补偿，但恢复依赖数千步逐场景优化，不适合 SCARF 的一次前馈和早期跳过路径。

### Mini-Splatting

[Mini-Splatting](https://arxiv.org/abs/2403.14166) 从点云空间分布出发，使用采样、交点保持和重新初始化改善受限 Gaussian 数量下的质量。它说明保留基元的几何覆盖比单纯按属性相似删除更重要，但其方法属于逐场景优化流程，不能直接放入 SAES 热路径。

### CompGS

[CompGS](https://arxiv.org/abs/2311.18159) 使用向量量化共享协方差和颜色属性，并通过 opacity 正则产生可裁剪基元。它支持 Gaussian 属性具有可复用结构这一前提，但聚类码本和联合训练不符合 SAES 不增加新预测模块的约束。

### Runnalls 高斯混合约简

[Kullback-Leibler Approach to Gaussian Mixture Reduction](https://www.cs.kent.ac.uk/pubs/2007/2797/) 使用一阶和二阶矩保持替代高斯分量，并以 KL 上界选择可合并分量。它为几何密度的矩保持和合并代价提供直接数学依据，但不处理 3DGS 的方向颜色和 alpha 合成。

### NanoGS

[NanoGS](https://arxiv.org/abs/2603.16103) 是最接近的直接先例。它在局部稀疏图上执行成对合并，使用质量守恒矩匹配和原则化合并代价，在不训练的情况下简化现有 Gaussian Splat。该工作已经覆盖训练后局部 Gaussian 合并，因此本项目不能把局部矩合并本身声称为新颖。

SAES 的不同约束是被删像素的 Gaussian 尚未实例化。直接采用 NanoGS 需要先运行完整 Adaptor，会失去 S3 加速。当前设计只借用质量守恒和局部兼容性原则，用探针 Gaussian 和相机几何解析覆盖未实例化像素；L0、L1、Full 的选择仍完全由论文路径选择器给出。

### FreeSplat

[FreeSplat](https://arxiv.org/abs/2405.17958) 在前馈多视图重建中进行像素级融合以消除跨视图 Gaussian 冗余。它说明前馈模型可以在生成路径中减少重复基元，但其问题是跨视图融合，不等同于 SAES 的 tile 内预实例化省略。

## 方案收敛

初始候选包括完整生成后合并、轻量神经残差预测和探针基元驱动的解析覆盖。完整生成后合并最接近 NanoGS，质量可控但失去 SAES 的核心吞吐收益。轻量神经残差预测需要新增训练和预测路径，违反模块边界。探针基元驱动的解析覆盖不运行非探针 Adaptor，不改变论文路径，并避免逐像素 softmax，因此被选中。

两句工程陈述如下。

> SAES 完全保留论文给出的 L0、L1、Full 选择。进入 L0 或 L1 后，根据真实探针 Gaussian 的空间密度、opacity 和方向球谐执行硬归属，再用相机几何的覆盖二阶矩扩展探针，不透明度按积分光学厚度守恒更新，球谐保持探针原值。

最强反对意见是探针不足以覆盖细小纹理或遮挡边界。设计用真实 Gaussian 的几何贡献、方向辐射和 opacity 建立无权重硬归属，并要求逐视图最坏质量通过。若固定路径内部算法不能同时满足质量和论文吞吐对照，则算法判定未通过并继续修改；不允许通过增加 Full tile、改变选择条件或放宽质量换取结果。

## 下一验证阶段

下一阶段不是继续扩展候选，而是在 MVSplat 与 RealEstate10K 的真实验证分割上完成以下测量。

1. 复现官方基线 Gaussian 和质量
2. 记录旧软插值的逐视图失败位置和 Gaussian 属性差异
3. 冻结论文路径标签，实现探针基元硬归属
4. 验证解析覆盖与光学质量守恒
5. 验证路径标签逐元素不变，并在质量约束下测量 SAES 省略周期

只有这组测量同时满足质量和吞吐合同后，才扩展到其他模型与数据集。
