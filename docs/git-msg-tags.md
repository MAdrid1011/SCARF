# Git Message Tags

Tags used in commit messages, issue titles, and PR titles for the SCARF project.

| Tag | Description |
|-----|-------------|
| `feat` | New feature or capability |
| `perf` | Performance optimization or tuning |
| `bugfix` | Bug fix |
| `refactor` | Code restructuring without behavior change |
| `docs` | Documentation changes |
| `test` | Test additions or modifications |
| `chore` | Build, CI, or maintenance tasks |
| `cleanup` | Code cleanup, dead code removal |
